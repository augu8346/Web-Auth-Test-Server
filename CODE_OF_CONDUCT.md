# Collaboration expectations

Be respectful, specific and constructive. Discuss the change rather than making
personal remarks about contributors. Welcome questions and explain technical
disagreements with reproducible evidence.

Do not harass, discriminate against, threaten or publish private information about
others. Do not include production credentials, private customer data or identifying
request logs in discussion, screenshots or attachments.

For ordinary technical disagreements, use the relevant issue or pull request and
ask a repository maintainer to help. For sensitive conduct concerns, contact the
repository owner through an existing trusted private channel; do not disclose the
details publicly. No dedicated reporting mailbox or response-time commitment is
currently published.

Maintainers may moderate content or restrict participation to protect constructive
collaboration. Apply these expectations consistently to issues, pull requests and
other project discussions.
